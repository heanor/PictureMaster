02 / Features

四大核心功能，
把版本控制简化到只剩一行账本

A · 增量快照系统

只备份变化的文件

每次创建快照时，Rust 核心扫描工作目录与最新快照的差异，仅备份变化的文件到 History/V{n}/ 目录。SQLite 账本记录每条变更的版本号、路径、哈希值、操作类型。

  • 基准快照1 份
  • 增量备份仅变化文件
  • 账本写入append-only
B · 本地 AI 解读

Gemma 本地推理 · 流式输出

所有模型在本机安全运行，零代码上传。AI 实时审计账本，生成「逐字吐字」的快照日志大白话总结。支持快照总结、项目概况、文件解读三种粒度。

local-llm · streaming tokens/s
audit range: t₃₇ → t₅₂ 2 files modified · 1 file added
C · 快照对比

左右目录树精准比对

点击任意快照的「查看变更」按钮，进入对比详情视图。左右两栏显示目标版本与最新版本的目录树，颜色高亮区分变更类型：蓝色=新增、橙色=修改、红色=删除、绿色=重命名。

  • 对比视图左右双栏
  • 颜色高亮4 类变更
  • 结果缓存避免重复计算

D · 无痕物理回滚

累积变更代价统计 · 一键导出

恢复到历史版本时，系统计算「需要清里的文件数」「需要倒滚的文件数」「需要补回的文件数」。回滚结果导出到用户指定目录，不触碰工作目录。

  • 回滚影响仅目标目录
  • 校验算法SHA-256
  • 导出方式独立副本
